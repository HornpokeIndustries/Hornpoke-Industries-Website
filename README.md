This repository is a collection of files used to create the Hornpoke Indusries Website. The Website conforms to a 
structured programming philosophy and schema architecture created outside of the GitHub mechanisms for 
creating and collecting materials for building a website. Hornpoke Industries encourages visitors to examine
the architecture schema as an example to how to create your own website. There will be ChatGPT sessions avaiable
that 1. help you understand and create repositories using the philosophy and schema architecure and .2 an suite 
of uploaders that conform to the philosophy and schema of architecture to push your documents to GitHub through
GitBash with a generic Upload Button that does the work of giving you the right program for the many different 
types of files while using the generic one desktop button...and .3 your GitBash scripts as well, can use the 
generic "one-generic-desktop-Gitbash-Loader button" from a corresponding local computer library for that purpose
which, if written in the philosophy and schema we designed for the project, can be pushed into the generic 
button that loads them automatically into GitBash. At the time of this ReadMe, these sessions have not yet
been uploaded for your perusal. The plan is to make GitBash and GitHub much simpler for any user that takes an
old computer and turns it into a GitHub Uploader and GitBash KIOSK for GitHub only...Which is also a ChatGPT session
that has not been uploaded yet. Do, not attempt to do this on your own, wait for the ChatGPT sessions to 
understand the code, and wait for the open-source code we are going to give you. After you see this, then 
modify the open-source work to your specific needs.
